Routing rule: chat-origin replies only

An agent's final message returns to chat only if the prompt came from chat

✔ chat-originated
chat room: @claude-1 "fix the bug"
↓ inject prompt, tag agent = owes 1 reply
agent works… finishes turn
↓ hook fires, tag is set →
final message posted to chat ✔
✘ typed directly in tab
you (in agent tab): "what's this file?"
↓ no chat tag set
agent works… finishes turn
↓ hook fires, no tag →
dropped — stays in the tab ✘

Edge case noted for later: typing directly while a chat prompt is in flight can race for the tag.
